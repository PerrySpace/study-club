### 朗读与跟读：听不清也要有反应

几个只有在实际陪孩子用过之后才会注意到的细节：

**语速按单位区分**。单字最慢（声调要靠拖长才听得出来），词语稍快，整句再快一点——都以「孩子跟得上」为准，而不是「听起来自然」。家长侧另有整体语速档位，可以再调。

**古诗念整首**。按「《题目》。朝代，作者。正文」朗读，孩子听到的是一首有来历的诗，而不是一串没有上下文的句子。

**跟读分三层降级**，全程只需要按一次：

| 情况 | 反馈 | 是否判对错 |
| --- | --- | --- |
| 识别引擎可用 | 「读得真棒！」/「再读一次」 | 判 |
| 引擎连不上（浏览器语音识别依赖厂商在线服务，国内网络常失败） | 改用本地音量检测，确认「确实有人读了」 | **不判**，并明确告诉孩子「只确认你读过了」 |
| 连麦克风都拿不到 | 记为已读，「已记录（这台设备听不到声音）」 | 不判 |

第二层尤其重要：**听得见声音不等于读对了**，界面不会把它显示成判题通过。识别期间有电平条，麦克风收到声音就会亮——这是「它在听我」最直接的证据。

**全部通关有鼓励**。一条内容线（识字 / 古诗 / 识字短文）全部完成时，结果页会播放一句中文鼓励加一句 `Good job!`，并常驻「再听一遍」。地图在这一刻显示完成横幅。

**已完成的关卡可以再进**。解锁只依赖「前一关是否完成」，所以回头复习哪一关都行，不会出现「打了绿勾却点不进去」。

### 一个账号，多个孩子 ⭐

**设置 → 孩子档案**：一个账号可放**多个孩子的独立进度**。每个孩子有自己的昵称、年级、头像与学习数据；「当前」的是正在学习的孩子，其余一键切换。孩子不用了可以**归档**，不打扰当前列表。新建档案只需昵称 + 年级 + 头像。

## 管理后台

单管理员后台（`apps/admin`，独立部署、不对公网开放）。覆盖内容全生命周期与站点配置。

### 登录与概览

登录只需管理员密码（部署时以 Argon2id 哈希配置）。概览一屏看清：内容规模、邀请码用量、各年级字库完成度、素材填充率。
