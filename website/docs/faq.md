# 常见问题

> 完整设计见 [docs/（Gitee）](https://gitee.com/perry-space/study-club/tree/master/docs)。本页汇总最常见的疑问，每条一句话给结论。

## 要不要手机号或微信？

**不需要。** 身份方式为**邀请码 + 自设密码**：用户名 + 密码即可注册登入。手机号 / 微信账号属**掩藏能力**（`enableAccountAuth`），写契约、默认关闭、不打包、不部署。

## 要不要企业主体？

**不需要**（掩藏能力除外）。产品**免费开放、开源、可自托管**，不收集儿童个人信息。只有手机号 / 微信账号、支付、小程序、App 上架等能力需要企业主体，这些能力当前**一律掩藏**。

## 数据存在哪？

**存在自托管的服务端。** MongoDB 是**服务端唯一真源**：账号、儿童档案、学习记录、复习状态、错题、徽章与内容都以服务端为准；浏览器只保留四类凭据与 UI 偏好键，不含业务数据。

- **可选端到端加密云档案**：`sync_objects` 存密文块，密钥由用户密码在客户端派生，服务端解不开；**默认关闭**，用户显式开启。
- **匿名统计**：只存聚合计数，不含任何账号或设备标识。

## 能不能离线用？

**PWA 可安装**，应用外壳与静态资源会被缓存，在线时永远取源站最新 HTML。但内容是受控数据，**登录后需要后端拉取内容与学习数据**，因此完整功能依赖服务端在线。

## 怎么改内容？

**改 JSON + 校验 + 导入**，不必发版：

1. 编辑 `content/**/*.json`；
2. 跑 `pnpm content:validate` 校验；
3. 跑 `scripts/seed/seed.sh` 导入 MongoDB。

详见 [内容体系与创作](/docs/content)。

## 怎么自己部署？

用 **Docker Compose 分服务独立编排**（mongo / api / web / admin），`scripts/dev/bootstrap.sh` → `up-all.sh` → `seed.sh` 即可起全栈。详见 [自托管部署](/docs/deploy)。

## 为什么没有教材同步？

**版权红线。** 单元按主题 / 难度**自编**，不复现任何出版物的单元顺序、课文标题与插图；「跟课本学」的需求由**用户自定义单元**满足（家长自己勾选字组成单元）。项目**永不提供教材映射数据**。

## 内容太少了怎么办？

**内容扩容是当前第一优先级。** 当前规模：汉字 83 / 古诗 3 / 单元 7 / 关卡 14 / 识字短文 5 / 徽章 7。系统设计已支撑规模化，欢迎贡献内容——只改 JSON 即可。详见 [贡献指南](/docs/contributing)。

## 怎么参与？

见 [贡献指南](/docs/contributing)：可贡献代码 / 内容 / 文档 / 测试 / 翻译 / Issue / Review，本地需 Node ≥ 20 + pnpm 9.12、Python 3.12、Docker。
