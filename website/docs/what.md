# 学习俱乐部是什么

> 本文是面向用户与贡献者的导读，完整设计见 [01-1 项目概述与定位](https://gitee.com/perry-space/study-club/blob/master/docs/01-产品规划/01-项目概述与定位.md)（Gitee）。

## 一句话定位

**跟着课本学汉字** —— 面向小学 1–6 年级的**课内识字 + 古诗文启蒙**应用，用游戏化方式解决「识字与遗忘」这个核心问题。

学习俱乐部（study-club）**免费开放、开源、可自托管**，当前版本 `0.1.0`（第一版可运行）。

## 目标用户

| 角色 | 是谁 | 核心诉求 |
| --- | --- | --- |
| **学生**（主） | 6–12 岁小学生 | 好玩、有成就感、看得见进度 |
| **家长** | 监督者与陪伴者 | 孩子学得怎么样、花了多少时间 |
| **教师**（选配） | 语文老师 | 布置作业、看班级掌握情况 |
| **内容运营** | 内部教研 / 社区 | 高效维护与扩充内容 |

> 使用主体是学生，家长是监督者。产品要同时满足「孩子愿意玩」和「家长看得到效果」。

## 定位边界

明确**不做什么**，比做什么更重要：

| 做 | 不做 |
| --- | --- |
| 小学课内同步识字（课标字表 + 自编单元） | 英语 / 数学等学科（当前不做，架构留余地） |
| 古诗文启蒙与背诵 | 写作技法、阅读理解技巧 |
| 游戏化练习与复习调度 | 真人直播课、一对一辅导 |
| 家长可见的学情报告 | 硬件产品、教具 |

## 三句定性

- **免费开放**：无付费墙、无会员、无广告、无内购。
- **开源**：代码 MIT；内容与文档 CC BY-SA 4.0。
- **可自托管**：后端运行在自有服务器上，只做「轻」职责。

## 当前状态（已实现）

| 模块 | 内容 |
| --- | --- |
| **学生端 / 家长端** | `apps/web`：Vue 3 + Vite + Pinia + PWA；手机 / iPad / 桌面三档响应式；学习地图、字卡、闯关、每日任务、复习、错题本、古诗、故事、学情报告、设置 |
| **云端后台** | `apps/api`：Python 3.12 + FastAPI + MongoDB 7；内容读取、邀请码身份、儿童档案、学习与复习、学情报告、匿名统计、反馈、素材托管、可选加密同步 |
| **管理后台** | `apps/admin`：Vue 3 + Element Plus；单管理员（内部工具） |
| **内容仓库** | `content/`：JSON + JSON Schema；`scripts/seed` 按表导入 MongoDB |
| **部署** | `deploy/`：mongo / api / web / admin 四份独立 compose + nginx 同源反代 |
| **跨端内核** | `packages/core`（零平台依赖 + 学科无关）、`packages/subject-hanzi`（识字专属）、`packages/tokens`（设计变量） |

### 内容规模（当前）

| 类型 | 条数 |
| --- | --- |
| 汉字 | 83 |

## 技术栈一览

| 层 | 选型 |
| --- | --- |
| 前端 | Vue 3 + TypeScript + Vite + Pinia + vue-router + PWA |
| 跨端内核 | `packages/core`（算法 / stores / 类型 / 契约 / 开关 / 仓储接口） |
| 学科包 | `packages/subject-hanzi`（拼音比对、题型生成、跟读判定） |
| 设计变量 | `packages/tokens`（三档断点 / 触控热区 / 色彩） |
| 后端 | Python 3.12 + FastAPI + MongoDB 7（motor 异步） |
| 身份与准入 | 邀请码 + 自设密码（Argon2id / JWT / Ed25519） |
| 内容分发 | 仓库内 JSON → 导入 MongoDB → `/content/*` 接口 |
| 部署 | Docker Compose 分服务独立编排 + `network_mode: host` + nginx |

## 关键概念

- **服务端权威**：学习数据、档案、进度与内容以服务端为唯一真源，浏览器只保留凭据与 UI 偏好。
- **内容即仓库**：内容与代码物理分离，贡献者只需改 JSON。
- **邀请码身份**：邀请码 + 自设密码注册登入 —— 不需要手机号、微信，也不需要企业主体。
- **掩藏能力**：需企业主体的能力（手机号 / 微信账号、支付、小程序、App）写契约、默认关闭、不打包、不部署。
