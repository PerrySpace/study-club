# 路线图

> 本文是面向用户与贡献者的导读，完整设计见 [01-3 功能清单与优先级路线图](https://gitee.com/perry-space/study-club/blob/master/docs/01-产品规划/03-功能清单与优先级路线图.md) 与 [02-4 架构演进与优化方向](https://gitee.com/perry-space/study-club/blob/master/docs/02-系统架构/04-架构演进与优化方向.md)（Gitee）。

> ⚠️ 本文是**方向清单，不是排期承诺**；不写时间线，只写「已完成 / 进行中 / 规划」。当前版本 `0.1.0`（第一版可运行）。

## 一、当前已实现（v0.1）

| 模块 | 能力 | 状态 |
| --- | --- | --- |
| 学生端 / 家长端 | 学习地图、字卡、闯关、每日任务、间隔重复复习、错题本、古诗、故事、学情报告、设置 | ✅ 已完成 |
| 多端适配 | 手机 / iPad / 桌面三档响应式 + PWA 可安装 | ✅ 已完成 |
| 身份与准入 | 邀请码 + 自设密码（Argon2id / JWT / Ed25519），可用 `REQUIRE_INVITE` 免码开放 | ✅ 已完成 |
| 云端后台 | 内容读取、儿童档案、学习与复习（服务端算）、学情报告、匿名统计、反馈、素材托管 | ✅ 已完成 |
| 云端档案同步 | 端到端加密，**默认关闭**、开启时默认加密 | ✅ 已完成 |
| 管理后台 | 概览 / 邀请码 / 字库 / 古诗 / 短文 / 用户 / 配置 | ✅ 已完成 |
| 内容工具链 | 内容即仓库（JSON Schema）+ CI 校验 + seed 导入 | ✅ 已完成 |
| 部署 | 四份独立 compose + `network_mode: host` + nginx 同源反代 | ✅ 已完成 |
| 跨端内核 | `packages/core`（零平台依赖 + 学科无关）、`packages/subject-hanzi`、`packages/tokens` | ✅ 已完成 |

> 约 98 个接口已部署；掩藏能力（手机号 / 微信、支付、小程序、App）**写契约、默认关闭、不打包、不部署**；**多角色 RBAC 后台属本期不做**（与企业主体无关）。

## 二、近期：补齐现有闭环

| 项 | 说明 | 状态 |
| --- | --- | --- |
| **内容扩容**（当前最大短板） | 字库扩至 1600 字（一、二年级）→ 3000 字；古诗扩至课标必背 75 首 → 150 首；短文与故事滚动扩充；音频与配图补齐 | 进行中 |
| 内容规模化 | 基础属性（拼音 / 笔画 / 笔顺）用白名单数据源批量生成；释义 / 组词 / 例句走人工或社区众包 | 进行中 |
| 管理后台补页 | 故事 / 单元 / 关卡 / 徽章维护页、古诗注音校验、内容导入 / 导出增强 | 规划 |
| 质量保障进 CI | 内容 Schema 校验接入 CI、`pnpm typecheck` 纳入 CI、掩藏能力「不打包」断言、端到端冒烟 | 规划 |

> 触发条件：**内容扩容始终是项目继续维护时的第一优先级**。

## 三、中期：体验与规模化

| 项 | 说明 | 状态 |
| --- | --- | --- |
| 内容下发与缓存 | 内容变大后改「先拉 manifest，按 checksum 拉变更文件」；列表分页与按单元过滤 | 规划 |
| 素材走 CDN | 音频 / 配图体积明显拖慢加载时，**改用对象存储 + CDN**（`ASSET_BASE_URL` 已预留） | 规划 |
| 服务端性能 | 热点索引复核；学情报告由实时聚合改为按需预聚合；单机 → 副本集（**不做分片，除非确有必要**） | 规划 |
| 学习体验 | 复习算法调参；题型自适应；声调跟读反馈；家长报告可视化；无障碍与低端机适配 | 规划 |

> 演进原则：**够用即止**——单人可维护是硬约束，不为「可能的规模」提前引入 Redis / 消息队列 / 微服务 / K8s。

## 四、长期：能力激活与生态

| 项 | 说明 | 状态 |
| --- | --- | --- |
| 掩藏能力激活 | 手机号 / 微信账号、支付、小程序、App 等，**代码与契约已就绪、开关默认关闭**，具备外部条件时是「打开开关 + 换一次注入」 | 规划 |
| 多云评测代理 | 付费语音评测 Key；**无 Key 时整块功能隐藏，绝不显示假分数** | 规划 |
| 多学科扩展 | `packages/core` 已按学科无关设计；从语文扩到英语 / 数学时复用发生在**能力层**（SRS、题型框架、身份、仓储、开关），学科走 URL 路径 `/hanzi` `/english` `/math` | 规划 |
| 内容社区化 | 降门槛贡献流程、众包审核、许可持续扫描进 CI | 规划 |
| 隐私与合规 | 数据上云告知与删除权、端到端加密常态化、部署位置决策、第三方许可合规 | 规划 |

> 扩科动机**只能是留存导向**（让现有用户待得更久），且带来的是内容生产与维护成本，不是收入。

## 五、明确暂缓 / 不做

| 项 | 结论 | 原因 |
| --- | --- | --- |
| Redis / 消息队列 / K8s / 微服务 | ⛔ 暂不引入 | 当前负载单机 + 单进程足够 |
| 多角色 RBAC 内容后台 | ⛔ 本期不做 | 单人维护下多角色属过度设计（**与企业主体无关**）；当前只做单管理员 |
| 音素级云端发音评分（默认） | ⚠️ 可选 | 按量计费会破坏「clone 即跑」 |
| 教材映射数据 | ⛔ 永不提供 | 涉出版社汇编权；改用「课标字表 + 自编单元 / 用户自定义单元」 |
| 数据库分片 | ⚠️ 暂不需要 | 数据规模远未到瓶颈，副本集足够 |
